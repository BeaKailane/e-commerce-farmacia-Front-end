# E-commerce Farmácia

Projeto de um e-commerce de farmácia desenvolvido com React e Vite.

## Tecnologias

- React
- Vite
- JavaScript
- HTML5
- CSS3

## Funcionalidades

- Listagem de produtos
- Página de detalhes do produto
- Navegação entre páginas
- Organização por categorias
- Interface responsiva

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/BeaKailane/e-commerce-farmacia.git
```

2. Entre na pasta do projeto:

```bash
cd ecommerce-frontend
```

3. Instale as dependências:

```bash
npm install
```

4. Execute o projeto:

```bash
npm run dev
```
